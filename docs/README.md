# База знаний log-collector

**log-collector** — расширение Zabbix для разбора инцидентов: при срабатывании триггера находит, с какого сервиса всё началось, и отправляет разбор ответственной команде.

Всё, что команда знает о продукте, требованиях и договорённостях. Правим через Pull Request, как и код.
