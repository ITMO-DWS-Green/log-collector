# Журнал решений

Каждое значимое решение — отдельная запись: что решили, почему, какие были варианты. Решения не удаляем; если передумали — новая запись со ссылкой на старую.

Статусы: **принято** · **предложено** (обсуждается) · **отменено**.

## Шаблон
```
## D-NNN. Название
Статус: предложено · Дата: ГГГГ-ММ-ДД · Кто: …
Контекст: почему вопрос возник.
Решение: что выбрали.
Альтернативы: что ещё рассматривали и почему нет.
Последствия: что из этого следует.
```

## D-001. Trunk-based development
Статус: принято · Кто: Роман Макеев
Решение: одна долгоживущая ветка `main`, короткие ветки под задачу, слияние только через Pull Request с аппрувом и зелёным CI. Подробности — в [README](../../README.md).

## D-002. Задачи и доска — в GitHub
Статус: принято · Кто: команда
Решение: задачи — issues в репозитории, доска — GitHub Projects организации ITMO-DWS-Green, спринты — milestones.
Последствия: всё в одном месте с кодом; PR связываются с задачами.
